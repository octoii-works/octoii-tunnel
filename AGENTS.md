# AGENTS.md

- **Clean Code**: clear names, small functions, no flag parameters, errors handled explicitly.
- **KISS**: the simplest design that works.
- **YAGNI**: build nothing before it is needed; no compatibility shims, change the API and migrate the callers.
- **Code style**: read like the code around it; [docs/code-style.md](docs/code-style.md) notes what the lint cannot check.
- **This file** changes only with the user's confirmation.
